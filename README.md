# To_Do_List_Manager

The To-Do List Manager is a simple Java console-based application designed to help users manage and organize their daily tasks. It provides essential task management features such as adding new tasks with a title, description, and due date, deleting tasks by ID, finding and viewing specific tasks, displaying all or only completed tasks, marking tasks as completed, and sorting tasks alphabetically by title. The program runs in a menu-driven format, allowing users to interact easily through number-based options.

This project is structured using three main classes: 

Task, which represents individual task dedetails 

Node, which forms the foundation of a custom linked list

TaskList, which manages the overall list and task operations using that structure. 

The main logic and user interface are handled in the ToDoListManager class, which allows the user to navigate the system seamlessly.
